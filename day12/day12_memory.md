Agent 的记忆分两种：

类型	作用	实现方式
短期记忆	记住当前对话	messages 列表
长期记忆	跨会话记住信息	向量库 / 数据库
举个生活例子：

短期记忆：你和朋友聊天，记得刚才说了什么。

长期记忆：你记得朋友的生日、喜好，即使上次聊天是三个月前。

长期记忆 = 跨会话记住信息。

问题：短期记忆只在当前 thread_id 有效。换个会话，就忘了。

解决：把重要信息存进向量库，下次检索。

架构：

text
用户输入
    ↓
┌─────────────────┐
│ 检索长期记忆     │ ← 从向量库找相关信息
└────────┬────────┘
         ↓
┌─────────────────┐
│ 拼接：记忆 + 问题 │
└────────┬────────┘
         ↓
┌─────────────────┐
│ 调用 LLM        │
└────────┬────────┘
         ↓
┌─────────────────┐
│ 存储新记忆       │ ← 把新信息存进向量库.
└─────────────────┘
