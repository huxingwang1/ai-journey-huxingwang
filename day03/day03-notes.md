Day 3 笔记

## System Prompt
- 设定 AI 的角色和行为规则
- 同一个问题，不同 system prompt，输出完全不同
- 例：小学生老师 vs 架构师，输出风格差异巨大

## Few-shot
- 在 prompt 里给例子，让 AI 模仿
- 控制输出格式和风格的最强手段
- 例：客服话术，有例子的会模仿"亲、哦~"的语气

## CoT（思维链）
- 让 AI"一步步思考"
- 加"请一步步思考"，推理过程显式化
- 适合复杂推理、数学题、逻辑题

## 结构化输出
- system prompt 里明确要求"只输出 JSON，不要任何其他文字"
- 给 JSON 格式示例
- 用 json.loads() 解析，处理异常

## 实用工具模式
- 输入文本 → AI 处理 → 结构化输出 → 保存
- 这是 RAG、Agent 的基础模式
- 例：批量提取人名/年龄/城市

## 踩的坑
1. AI 输出的 JSON 可能带 markdown 代码块
2. json.loads() 可能失败，要 try/except
3. 重试机制能提高稳定性
